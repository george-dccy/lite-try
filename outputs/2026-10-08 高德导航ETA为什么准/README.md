# 为什么高德地图驾车导航的“预计到达时间”这么准？

第一期机制解释样片。主叙事是“规则型”：把终点 ETA 拆成路段级预测，再按预计进入每段路的时间向前推演，最后用实际轨迹评估。

## 当前范围

- 画幅：1920×1080 横屏。
- 语法：白板讲解 + 路径/时间轴动态图表；不是产品录屏，也不是高德内部实现复刻。
- 素材：开场使用真实 AMAP ETA 界面截图，未来预测段加入 H3 Lite 生成的小男生机制插入镜头。
- 旁白：火山复刻 2.0 音色 `S_LNoN0nh22`，逐字时间戳已接入。
- 交付边界：只生成本地可审阅文件，不自动发布。

## 文件

- `scenes.js`：唯一手写的旁白、场景和封面源文件。
- `旁白稿.md`、`scenes/`、`字幕.srt`、封面：运行时生成物。
- 事实链与选题门禁：见 `../../research/2026-10-08 高德导航ETA为什么准/`。

## 验收重点

1. “预测”与“保证”不混用。
2. 每个关键数字/模型名都能回到事实链；本片只使用有出处的 11 分钟示例作为机制示意，不当作实测。
3. 路段、时间轴和反馈闭环随旁白推进，不能只做静态 PPT。
4. 最终抽帧检查字幕区、水印区、文字可读性和异常跳变。
