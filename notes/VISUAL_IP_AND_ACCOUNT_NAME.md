# 余光所及｜有解：账号名与固定视觉 IP

## 推荐组合

### 账号名：余光所及｜有解

“余光所及”负责打开范围：科学、技术、制度、商业、生活和人的处境；“有解”负责表达态度：不满足于看见现象，要继续追问机制和选择。它不把账号锁在 AI、银行或某一种知识类型里。

### 视觉 IP：解解

一个拟人化的小男生角色：

- 年龄感：小学高年级到初中低年级，聪明、好奇，但不是幼儿卡通。
- 外形锚点：深蓝短发，右侧一个橙色括号发夹；深蓝外套、橙色内搭、米白长裤、橙色斜挎包、蓝白运动鞋。
- 性格：会追问、会怀疑、会把复杂东西拆开，但不摆专家姿态。
- 道具：证据卡、放大镜、笔记本、电脑；每期只拿与主题有关的一个。
- 禁止漂移：不变成机器人、不变成地图导航员、不换成西装商务人、不使用泛 AI 大脑图标。

## 固定动作语言

1. “解解”先把一个复杂问题框出来，眉头微皱或指向关键处。
2. 翻开笔记本，把变量、证据和关系一层层摆出来。
3. 遇到证据时举起卡片，卡片上放真实来源或短句。
4. 结尾合上笔记本，给观众一个能复述的结论动作。

## 固定视觉规则

- 主色：深蓝 `#163B73`、明蓝 `#2F80ED`、橙色 `#F47B20`、纸白 `#F8F7F2`。
- 不画地图针、不画机器人、不画通用 AI 大脑、不让 IP 抢过证据和机制。
- 封面只露完整角色或半身；机制画面允许角色变成节点、箭头或路线上的小标记。
- 真实截图/新闻画面保留原色；“解解”只作为叠加的解释角色，不伪装成素材中的真实人物或产品。

## 账号名备选

1. Devin有解 —— 个人品牌感强，适合突出作者本人。
2. 一件事的系统 —— 内容理念最准确，辨识度高。
3. 解解这个 —— 视频号传播性最强，但要防止 IP 反客为主。
4. 生活有解 —— 亲和力好，适合做栏目名或大众入口。

当前正式品牌为“**余光所及｜有解**”，固定 IP 为“**解解**”。旧的“复杂有解”仅保留为历史候选，不写入片尾、封面或水印。

## ChatGPT 外部咨询结果（2026-10-09，已降级为命名参考）

已在用户打开的 ChatGPT 内置浏览器中，基于本人的知识/AI/自动化方向和本项目未来路线做了一次命名咨询。结论与当前判断一致：

1. `Devin有解`：最适合长期个人品牌，能覆盖 AI、自动化、产品、商业、银行和生活机制。
2. `一件事的系统`：内容哲学最准确，辨识度高，但不像常规账号名。
3. `解解这个`：视频号传播性最强，但需要严格控制 IP 的幼稚化风险。
4. `生活有解`：亲和力好、题材宽，适合作为栏目名或大众入口，但“生活”会把专业内容预期拉向生活窍门/成长内容。

外部咨询曾推荐 `Devin有解`、`一件事的系统` 和 `解解这个`。经过当前品牌定位更新，它们全部降级为栏目/个人子品牌备选；总品牌使用“余光所及｜有解”。
