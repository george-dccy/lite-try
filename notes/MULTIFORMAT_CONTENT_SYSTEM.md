# 一题多种内容操作流程

2026-10-11。品牌服从 BRAND_POSITIONING.md；本流程覆盖此前仅面向科技视频的生产规则。执行入口为项目自有 relationship-content Skill。

## 启动

“今天做什么”给三张候选卡；用户给出具体题且说“做这个”视为选题已确认。用户可以指定文章、文字卡片、视频、图片故事，或说“整套”。“整套”默认前三种，加一份图片故事；单一形式请求不扩展成整套。

## 共用内容简报

先保存 episodes/<日期 主题>/内容简报.md，包含读者、触发场景、原话、一个核心问题、一条判断、材料来源、可用案例、缺口及选择理由。

真实经历、公开资料、作者观点和演绎场景分别记录。书籍记录书名、作者、相关页码或章节；未读原文不能伪造书中原话。没有案例时可生成演绎场景，不冒称用户亲历。

可访问的相邻样本写入 research/<主题>/爆款拆解.md。分别拆文章开头和推进、图文首图和逐页承诺、视频前 3 秒和前 10 秒、节奏和画面。互动数缺失写“未获取”，不能用标题猜爆款。

## 母稿与关系判断

公众号长文先执行 `notes/ARTICLE_EDITORIAL_WORKFLOW.md` 的研究、内容扩充、章节设计与逐节审稿。用户经历是入口，不是全部材料；不得从口述直接跳到薄稿，再靠补字数或堆研究凑成长文。用户指定先长文后派生时，以审阅通过的长文为母稿。

Gemini 从简报直接生成内容母稿，保留原始初稿。母稿记录事件经过、双方处境、关键分歧、建议及适用条件，无固定字数，也不要求先写完长文再压成视频。

主 Agent 校对材料、压缩重复并做 deai-promax 清理。需要妻子经验时集中提交几个具体问题，如“这句回应真实可行吗”“哪一方的处境遗漏了”，将尚未回填的判断标记在后台，不冒称她已审阅。她的反馈应直接进入母稿，再同步影响各个版本。

## 改编与技能路由

关系题材图文按 notes/BRACKET_NARRATIVE_FORMAT.md 的原创括号叙事语法设计。归藏提供 Editorial 页面结构与渲染工具，不代表项目全篇采用上下双格漫画模板。

| 交付 | 内容设计 | 主路由 |
| --- | --- | --- |
| 公众号文章 | 场景、经过、解释、选择，允许展开，标题单独打磨 | Creator Buddy 的 gzh-longform-writer / gzh-short-post；gzh-design 排版与校验 |
| 文字型配图卡片 | 一页一个推进点，封面提出具体困惑，内页用对话或行动说明 | guizang-social-card-skill，优先 Editorial；小红书标题和配文借 space-xhs-title / space-xhs-writer |
| 视频 | 独立写口播，先动作和对话，精确分镜，不朗读文章 | space-video-script → Huashu 镜头表与检查 → Visual Master Sheet / Shot Pack → 配音、字幕、动态画面、验收 |
| 图片故事加配文 | 图片承担事件和关系变化，文字只补必要上下文 | hand-drawn 提示词 → 可用生图工具 → 配文与逐图验收 |

同一主题各形式共享事实与判断，不共享全部句子。改动核心判断后，检查所有派生版本是否一致。

## 上游复用选择

- 归藏：复用原模板、页面规划和渲染器；暖纸杂志系统适合本品牌的文字型卡片。其“不支持情感梦核装饰风”是视觉范围限制，不是禁止关系话题。素材来源按本项目记录且核对许可，不能将“抓图后再由用户判断”作为默认生产策略。
- CY：安装为技术备选，AI 科技笔记不是新账号默认模板。学习其反差入口、例子推进、逐页目检、来源表与交付打包；不强制 11 页、电子青或毛笔标题。macOS OCR 分支不可冒称 Windows 已跑通。
- Creator Buddy：复用现有写作、选题、样本分析、标题及配文技能。科技专用标题和科技紫封面不作为情感内容默认。
- 甲木：使用主题组件库、内联样式、复制预览页和校验脚本；按用户“自动化”的意图自动推荐主题，首个品牌样式可集中审阅。
- 手绘：提供画风配方和提示词，不提供生图服务。正式 3.1/19/20 风格分别有多阶段/锚点/验收要求，依赖齐备才执行。不能只拿一段提示词冒称已做插画。
- 微信图文变现：保留为商业化参考；商品关联和复盘可借鉴，不自动开橱窗、不进行矩阵发布，不使用素材去重规避原创判断。规则和开通条件到需要时再核实。
- Huashu：视频主引擎，沿用当前 clone 绑定 S_iGgUZmh22；配音依据纯文本，镜头表依据真实音频时长重新对齐。H3 插入动态片段，不能拿末帧代替动画。

## 对标质量门

内容结构、账号增长、商业路径分别核实。主页粉丝数或挑一条最高互动，不能独立证明可复制。只见商品露出就记录“品牌植入”，合作费、销量和利润无来源时记“未获取”。只见招募或私信引导就记录“获客承接”，未看到收费、交付和成交证据时不称付费模式跑通。样本表现差异明显时写出互动范围；达不到三个通过标准的账号，就报告实际合格数量。

## 平台适配与完成标准

先做可读的源版，再按平台分别排封面、标题、文字量、安全区与画幅；平台规格以执行时文档及上传入口为准，不承诺同一个文件在各平台最佳。视频按题材决定竖版/横版；B站需要横版时独立构图，不能拉伸竖版。

公众号 HTML 跑对应校验并提供复制预览；卡片核对尺寸、溢出、缩略图可读性，逐页看原图；插画核对人物一致、动作、关系及文字；视频核对音色、字幕、声画对应、真实动态和空帧。

交付清单明确已生成、未生成、已目检和未目检项目。Skill 安装与流程编排完成，不等于多平台端到端生产已跑通。不自动公开发布。
