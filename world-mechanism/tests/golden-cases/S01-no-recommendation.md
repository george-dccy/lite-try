# Golden Case S01 — 首页只有十把椅子

**类型**：当代社会 / 技术 / 思辨解释  
**状态**：Golden Case，2026-10-01 人工认可  
**主要测试**：非故事型机制内容、多方激励、读者推理推进、非二元价值判断

## Why it became Golden

S01 经历了完整链路：

1. 原始直觉：“关掉推荐算法会不会更真实？”
2. Mechanism Explorer 发现“算法消失”定义含糊。
3. Operationalize 为“取消首页个性化预测排序”。
4. 从 Search Cost / Attention Allocation / Ecosystem Feedback 中确定主机制。
5. 放弃确定性 Day 1 → Day 3 → Day 7，改用替代机制分支。
6. Creative Director 判断“不应强迫写剧情故事”。
7. 编译成《首页十把椅子》Content Master 与完整文章试写。
8. 作者人工反馈：
   - 内容“挺惊艳”；
   - “符合我的气质”；
   - “让人想跟着思路读下去”；
   - “可以照此推进”。

因此它不再只是候选，而成为**第二个正式 Golden Case**。

## Core Mechanism

> **当内容比注意力多得多，第一次筛选不可避免；取消个性化推荐不会消除中介，只会改变谁分配稀缺注意力、谁承担寻找成本。**

## Creative Device

> **首页只有十把椅子。**

让读者依次选择：
- 时间顺序；
- 只看关注；
- 搜索；
- 人工编辑；
- 热门榜。

每个方案先成立，再由自身机制暴露新的代价。

## Why the writing works

不是“观点 + 五个论据”。

而是：

> 读者提出一个合理答案 → 规则真的运行 → 新问题出现 → 读者被迫升级自己的问题。

真正被 Golden Case 固化的是：
> **让读者经历机制，而不是听作者宣布机制。**

不是：
> 所有文章都必须有五轮选择或十把椅子。

## Must Preserve

- 不把个性化推荐等同于所有算法；
- 无推荐不等于无中介 / 无排序；
- 替代方案都必须被认真对待，不写稻草人；
- F / I / H 严格分层；
- 不替读者做算法善恶裁决；
- 每一节都改变读者的认知状态；
- 结尾升级问题，不喊口号。

## Regression Questions

1. Mechanism Explorer 会不会直接输出“算法让人上瘾”？
2. Research Agent 能否区分真实平台机制和思想实验？
3. Creative Director 会不会强迫它变成一个孩子的剧情故事？
4. Content writer 是否提前宣布“真正的问题是中介”？
5. 每个替代规则是否先获得公平表达，再暴露代价？
6. 结尾是否仍把选择留给读者？
7. 文章是否仍让人“跟着思路读下去”，而不是读一篇结论说明书？
