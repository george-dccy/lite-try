# Golden Candidate H01 — 北京时间为什么在西安产生？

**类型**：中国历史 / 科学 / 技术 / 制度  
**状态**：Golden Candidate，v0.4，待人工确认  
**主要测试**：China-first、Truth Surprise、历史纵深、公共基础设施

## Core Question

> **“北京时间”为什么由西安临潼的国家授时体系产生和保持？一个国家又怎样让亿万人共享同一个未来时间坐标？**

## Core Mechanism

第一层：
> **标准时间让陌生人共享未来坐标。**

第二层：
> **这个坐标必须持续被产生、保持、校准和传播，因此标准时间本身是一项公共基础设施。**

## Why earlier versions failed

### v0.2 — 美国铁路 / 电报送信少年
史实可以成立，但文化距离太远。

### v0.3 — 一张车票上的14:37
现代、易懂，但属于“统一时间”最直接的第一联想，正确却普通。

两次失败共同形成 Creative Director 的规则：

> **第一联想只做 baseline；事实真实也不等于表达有效。**

## v0.4 Truth Surprise

- 国家标准时间（北京时间）的产生、保持和发播任务由中国科学院国家授时中心承担；
- 中心总部位于陕西西安临潼；
- 北京时间采用东八区标准时间，对应东经120°标准经线，并不等同于北京当地的地方太阳时。

这让问题自然发生：

> 如果北京时间既不是“北京太阳的时间”，也不必须在北京产生，那它究竟是什么？

## China-first Historical Depth

主叙事从中国自身延伸：

- 传统“观象授时”、历法与时间秩序；
- 宋代完整时间测量与授时体系；
- 元代《授时历》；
- 1949年后“北京时间”名称与推广；
- 20世纪60年代陕西专门授时体系；
- 原子钟、长短波、卫星导航与现代国家时频体系。

注意：
> 这是“问题连续性”，不是说古代授时技术等于现代标准时间。

## Must Preserve

- 中国视角为主，世界材料只做比较和国际体系说明；
- “北京时间在西安产生”是真实入口，不做噱头后立即丢掉；
- 共享未来坐标 + 授时基础设施双层机制；
- 不把古代授时写成现代全国精确同步；
- 不说普通手机都直接从西安取时；
- 不退化成“北京时间冷知识”；
- 不重新回到火车时刻表做主入口。

## Regression Questions

1. 创意是否从中国真实惊讶出发？
2. “西安”是否真正引出了标准时间机制，而不是地理冷知识？
3. 是否能从“时间为什么要授”进入中国历史纵深？
4. 儿童层是否能理解“很多机器需要同一个时间”？
5. 成人层是否自然看到“标准是一种基础设施”？
6. 世界案例是否保持在辅位？
