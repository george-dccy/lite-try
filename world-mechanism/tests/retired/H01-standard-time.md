# Retired Case H01 — 标准时间 / 北京时间

**状态**：Retired — 2026-10-01  
**原因**：核心机制虽可解释，但连续三轮表达都未达到作者要求；继续优化会把项目拖回“科普钩子”而非真正的认知创造。

## 三轮失败记录

### v0.2｜美国铁路 / 电报送信少年
- 文化距离远；
- 观众需要先理解旧职业与美国历史；
- 史实真实，但表达入口无代入感。

### v0.3｜一张车票上的 14:37
- 清楚、正确；
- 但属于统一时间最常见的第一联想；
- 没有足够的认知位移。

### v0.4｜北京时间为什么在西安产生？
- 有真实反直觉事实；
- China-first 方向正确；
- 但本质仍然是“冷知识钩子 → 知识解释”，偏科普；
- 没有像 S01 那样让读者亲自拆掉自己的原有理解。

## Retired Learning

1. **Knowledge Surprise ≠ Cognitive Surprise**  
   “我告诉你一个不知道的事实”弱于“你自己原来的理解方式失效了”。

2. **机制正确 ≠ 选题值得继续**  
   如果作者对核心问题本身不再有继续追问欲望，应停止，而不是继续优化表达。

3. **不要把新的深层感受硬塞回旧题**  
   当新的思考已经从“标准时间”转向“个体有限性与当下体验”，应建立新母题，而非强行继承旧 ID。

4. **Retire is a valid outcome**  
   世界机制故事引擎必须允许主动放弃已经投入很多工作的题目。沉没成本不能成为继续创作的理由。
