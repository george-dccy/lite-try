## 1. 这支片不是“文章配画面”

真正的导演命题只有一个：

> **怎样让观众先渴望同时拥有更多世界，然后亲自发现：世界可以并行，但体验只能沿一条线发生。**

所以画面的任务不是解释旁白，而是完成四次实验：

1. 同时全部；
2. 逐个回放；
3. AI总结；
4. 只选精彩。

最后让四种方案全部退场，只留下：

> `08:00:00 → 08:00:01`

这就是本片最终的 Visual Proof。

---

## 2. 关于 v0.4 文案如何进入视频

v0.4 继续作为完整文字母版，不再为了视频反复改哲学表达。

视频制作另做一个 **Narration Cut**：

- 不是重写文章；
- 只从 v0.4 中删掉已经被画面证明的解释句；
- 保留问题链、四次升级、三个关键句与结尾；
- 目标约 1:50–2:20；
- 画面已经完成论证的位置，允许 2–4 秒完全无旁白。

这一步属于剪辑/导演适配，不回写 Content Master 的思想。

---

## 3. 总体视觉方向：真实世界是“母语”，艺术风格是“其他世界”

### 推荐方向 A｜Real → Many Worlds → Real

这是首选。

- **我的生活**：偏真实、克制、连续。人物用生成帧或真实感角色帧，代码负责镜头与合成。
- **别处的生活**：使用多种艺术风格，让“世界并行”不仅是内容不同，连视觉语言也真的不同。
- **AI世界**：突然收敛成干净 UI / 动态文字，信息更完整，但空间感消失。
- **高光筛选**：短暂进入 art-history speedrun 式风格跃迁。
- **结尾**：所有视觉炫技撤走，回到开场人物和具体声场。

优点：风格变化本身就是论证，不是装饰。

### 备选方向 B｜全片当代扁平 + 语法变化

统一 `16_2026` 视觉体系，只改变分屏、长卷、UI、相机和转场语法。

优点：最统一、风险最低。
缺点：没有充分吸收 art-motion 的多风格优势。

### 备选方向 C｜中国水墨为底 + 数字世界侵入

主体使用 `17_ink`，其他世界逐渐以像素、波普、印象派、UI等形式侵入。

优点：作者性强。
缺点：很容易让“中国水墨”成为额外文化命题，抢走时间主题。

**首轮只做 A/B/C 三张同一时刻的 keyframe，不先做整片。推荐 A。**

---

## 4. 统一外壳：即使多风格，也必须看起来是同一支片

为了防止变成“35种画风展示”，全片锁四个统一元素：

1. **同一个参考时间系统**：`08:00:00` 是全片唯一稳定数字锚点。
2. **同一个窗口几何系统**：所有世界都从同一种窗口/画框逻辑生长出来。
3. **同一个主体运动方向**：开场和结尾人物都沿同一主要方向前进。
4. **同一个声音原则**：具体生活有空间；摘要信息没有空间。

视觉风格可以变，但这四件事不能变。

---

## 5. Sequence 设计

### S1｜我的这一秒｜15s

**任务**：先让观众真的进入一条生活。

画面：普通中国城市早晨。人物出门、街口、早餐点、等灯或走向通勤入口。

风格：
- Direction A：真实感角色 + 写实/轻插画环境；
- 不追求“电影感”，重点是可信。

镜头：3–4镜，不快切。

声音：脚步、车流、近处塑料袋、远处说话。

时间：结尾出现 `08:00:00`。

**禁止**：杯子、固定仪式、煽情家庭动作。

---

### S2｜世界打开｜18s

**任务**：让更多世界先变得诱人。

窗口：2 → 4 → 8 → 16。

建议先准备 8 个 ordinary worlds：

| world | 动作 | 视觉候选 |
|---|---|---|
| W01 | 傍晚下班推门 | Hopper |
| W02 | 雨中收伞进屋 | 水墨 |
| W03 | 海边跑步 | Monet / Impressionism |
| W04 | 室内收衣服 | 2026 flat |
| W05 | 夜里小餐馆吃饭 | Hopper |
| W06 | 孩子学骑车 | contemporary flat / generated sprite |
| W07 | 深夜等车 | 8-bit 少量反差 |
| W08 | 黄昏阳台浇花 | Matisse / Impressionism |

规则：
- 前 8 格每格必须能读懂“这个人在做什么”；
- 不使用世界地标；
- 不把异国感当成“世界丰富”的替代品；
- 每个窗口内部必须持续有动作。

---

### S3｜全部拥有｜10s

**任务**：第一次 Visual Proof。

把 16 格继续扩到 64+。

关键不是“乱”，而是让观众经历三个阶段：

> 还能选 → 选不过来 → 根本没有前景。

程序实现：
- window grid 参数化；
- 每个窗口保留低成本循环；
- 窗口越小，信息细节越少；
- 声音随窗口数量递增；
- 最后 0.2–0.4 秒突然静音并只留一个窗。

---

### S4｜那我一个个看｜17s

**任务**：第二次实验必须认真成立。

复用 huashu `long_scroll` 的核心骨架：

- 一个窗口被放大；
- 看清以后向侧面离开；
- 后面永远还有下一段；
- 相机只进不退；
- 队列的“未看部分”始终可见。

这里可以把不同风格世界排成一条真正的连续长卷，而不是普通卡片列表。

声音：每进入一段，空间声恢复；一离开又被截断。

---

### S5｜让 AI 总结｜15s

**任务**：让“知道很多”看起来真的高效。

语法：
- 主：`t2_keynote_ui`
- 辅：克制使用 `y5_kinetic_type`

画面：
- 一个数字；
- 一个类别；
- 一张代表图；
- 一个关键词；
- 每屏只讲一件事。

不要假装任何真实 AI 产品，不出现品牌 UI。

最重要的变化：**声音失去方向和距离**。

---

### S6｜那就只选最好的｜15s

**任务**：这是 art-motion 最能发挥的地方，但只能短。

4–6 个高光，每个 2–3 秒：

- 日落：Shinkai / Impressionism；
- 夺冠：Pop；
- 重逢：Matisse / contemporary flat；
- 求婚：可用 Klimt 或轻写实；
- 海边：Monet；

每一段遵守：

> 主动作 → 母题小循环 → 签名转场。

最后不要继续漂亮下去。

所有高光突然缩回几张互不相连的卡片。

这时不要用旁白马上解释；让 1–2 秒的“没有共同声场”自己说话。

---

### S7｜08:00:01｜24s

**任务**：全片最重要的一段。

画面回到开场人物，而且：

- 不再换艺术风格；
- 不再开窗口；
- 不再出现 UI；
- 镜头运动变得连续；
- 声音恢复完整空间。

人物继续走完刚才没有走完的一步。

`08:00:00`

停留。

然后：

`08:00:01`

这两个数字不能做成“金句动画”，只是时间自然变化。

可选实验：人物走过的路径后方短暂留下一根极细轨迹线，0.5–1 秒后消失。若审片者觉得“像哲学示意图”，立即删。

---

### S8｜世界仍然在那里｜12s

人物继续向前。

其他生活不再通过正面分屏回来，而只通过：

- 橱窗反射；
- 远处窗户；
- 画面边缘极短的视觉回声；
- 声音里很轻的远层。

它们仍然存在，但不与主体争夺“谁更值得”。

普通动作或黑场结束。

---

## 6. 第一轮只做什么

不要直接渲整片。

### Gate 1｜三个 Keyframe

同一个 `08:00:00` 场景出三种方向：A / B / C。

验收：
- 哪一张最像“我们的作品”，而不是 huashu demo？
- 人物是否可信？
- 风格是否承担主题？

### Gate 2｜三个 Motion Prototype

只做：

1. S2：2→8格世界打开（5–8s）；
2. S4：长卷回放（5–8s）；
3. S7：08:00:00→08:00:01（6–10s）。

这三个片段分别验证：

- 多世界；
- 无限回放；
- 单一时间线。

三段都成立，才进入整片。

### Gate 3｜Narration Cut + word timestamps

从 v0.4 中剪出生产旁白，不重新写观点。

交付：
- narration.md
- narration.wav
- words.json（词级时间戳）

### Gate 4｜Motion Plan

每一句旁白映射：

```yaml
start:
end:
spoken_text:
cognitive_job:
scene:
grammar:
style:
camera:
action:
transition:
audio_cue:
subtitle_safe_zone:
```

### Gate 5｜整片 rough cut

先只追求：
- 逻辑成立；
- 节奏成立；
- 风格切换有理由；
- 声音论证成立。

不要在 rough cut 阶段精修每个角色。

### Gate 6｜QA / 独立审片

必须：
- 跑 upstream `qa.py`；
- 浅底片段跑字幕区检查；
- 至少一个没参与制作的 agent 只看成片；
- 记录 timecode → 问题 → 根因 → 修改 → 复验。

---

## 7. 资产策略

### 必须生成

- 固定主人物：至少 6–10 个动作帧/姿态；
- 少量人物细节较强的世界窗口；
- 高光片段里代码难以完成的人物动作。

### 优先代码绘制

- 窗口系统；
- 64格过载；
- 长卷；
- AI摘要；
- 动态文字；
- 艺术材质；
- 风格转场；
- 时间数字；
- 相机运动；
- 图层后期。

### 声音优先级

这支片的声音不是后期装饰，而是第二条论证线。

优先顺序：

1. 主体生活真实空间声；
2. 多窗口声场叠加；
3. 静音断点；
4. 摘要去空间化；
5. 回归空间声；
6. 音乐最后才加。

---

## 8. Definition of Done

F01 第一支成片只有同时满足这些条件才算完成：

- 不看字幕也能理解“从一个世界 → 太多世界 → 回到一条线”的运动；
- 多风格出现有叙事理由，不像 showreel；
- 观众不会把结论理解成“别看远方”“平凡最珍贵”或“人生就是遗憾”；
- 杯子逻辑完全不需要；
- `08:00:00 → 08:00:01` 不靠旁白解释也成立；
- 声音能独立完成“具体 → 拥挤 → 无空间 → 具体”的变化；
- 最后一段比前面更简单、更安静，而不是更宏大。
