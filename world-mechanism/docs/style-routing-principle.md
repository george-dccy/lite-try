# Content-Driven Visual Style Routing

## Principle

Visual style is selected **after** the creative mechanism and intended audience experience are understood.

The World Mechanism Story Engine has no universal house style that every film must inherit.

> **Content and cognitive function choose the visual language; production convenience does not.**

## Inputs to style routing

Before choosing a style, read:

1. Core Cognitive Turn;
2. dramatic / explanatory form;
3. Visual Argument;
4. Temporal Device;
5. Sound Argument;
6. protagonist / subject requirements;
7. cultural position;
8. production constraints and available renderers.

## Valid outcomes

A production may deliberately choose:

- one unified visual style;
- multiple sectional styles;
- simultaneous parallel-world styles;
- realistic / photographic treatment;
- painterly or illustrative treatment;
- Chinese ink or another culturally grounded visual language;
- collage / archival / whiteboard / diagrammatic / UI-led motion;
- code-drawn graphics with generated character assets;
- bounded generative-video clips;
- a hybrid of several media.

Art-motion's style catalog is a vocabulary, not a checklist.

## Decision test

For each style or medium choice, record:

- **where** it appears;
- **what job** it performs;
- **why this content needs it**;
- **what simpler option was considered**;
- **what continuity cost it creates**;
- **how it will be produced reliably**.

Do not prefer one style because a previous film already used it successfully.

Do not prefer multiple styles because the renderer supports many styles.

Do not prefer a single style merely because it is cheaper unless that constraint is consciously accepted as part of the production decision.

## Project vs case-specific decisions

Keep these levels separate:

### Project-level rule
Every film performs content-driven style routing.

### Case-level decision
A particular production may lock one visual direction after its own routing decision.

Example:

- F01 Pilot currently chooses unified contemporary illustration to isolate temporal/window/context mechanics and exploit economical local motion generation.
- This says nothing about the correct style for S01, A08 or future projects.

Case decisions must never silently become project defaults.

## Relationship to art-motion

The project should continue to inspect and learn from the full art-motion style and grammar library.

Absorbing art-motion means increasing the available visual and motion vocabulary, not forcing every production to use all of it or any fixed subset of it.

The ideal routing question is:

> **What visual system makes this particular mechanism easiest to feel, not merely easiest to render?**
