# Decision — Style routing scope

Date: 2026-10-07

## Decision

The World Mechanism Story Engine does **not** use one default visual style across all productions.

F01's unified contemporary illustration direction is a **case-specific Pilot decision** made to simplify the first production test and fit local dynamic-asset generation. It must not become a global inheritance rule.

## Project-level invariant

Every new production performs content-driven visual routing after its creative mechanism and intended audience experience are understood.

The router may recommend one style or many styles, realism or illustration, collage, archive, UI, whiteboard, Chinese ink, generated assets, code-drawn motion or hybrids.

## Reason

The project exists to compile different kinds of thought into the visual language that best expresses them. Locking one house style would let production convenience shape upstream creative decisions, contradicting the architecture principle that understanding and content precede expression tools.

## Consequence

- F01 keeps its current unified illustration Pilot direction unless its own prototype fails.
- S01, A08 and future works must route styles independently.
- Codex must never copy a previous film's style solely because the implementation already exists.
- art-motion's style library is treated as a vocabulary to choose from, not a fixed brand kit or a checklist.
