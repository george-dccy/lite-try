# Cultural Lens — China-first, World-second

## Default stance

世界机制故事引擎默认采用：

> **中国视角为主，世界视角为辅。**

这不是“所有题都强行中国化”，也不是排斥世界经验。

它解决的是一个真实偏差：大模型的公共资料分布和常见案例非常容易把创作自然带向美国互联网、美国铁路、欧美制度史。久而久之，作品虽然正确，却会与创作者、孩子、家人和中文读者的真实生活脱节。

## China-first 的含义

在题目进入 Creative Exploration 前，默认先检查：

1. 中国历史里有没有更深、更长的同类机制？
2. 中国今天的日常生活里有没有更直接的入口？
3. 中国制度、科技、城市、家庭经验里有没有只有本土语境才成立的反直觉事实？
4. 中国案例是否能降低理解门槛，而不是提高门槛？
5. 能否从中国案例出发，再用世界材料验证“这是普遍机制还是特殊路径”？

如果答案成立，中国材料进入主位。

## World-second 的作用

世界材料主要用于：

- 对照：别的社会如何解决同一机制问题；
- 校准：避免把中国特例误认为普遍规律；
- 扩展：说明机制怎样在不同制度、技术和文化里变形；
- 补证：当中国公开资料不足时提供高质量研究证据；
- 连接：把中国故事放进更大的世界历史与科技演化中。

## 不强行中国化

下列情况可以直接以世界 / 外国案例为主：

- 题目本身就是特定外国历史或制度；
- 关键科学发现与具体海外事件不可分；
- 中国案例会让机制更难理解；
- 为了“中国视角”而硬换人物、地点，会损害事实与创意。

## Creative Gate 新增问题

每个候选都要过：

### Cultural Position
- 为什么这个入口应该从中国讲？
- 如果换成美国 / 欧洲案例，损失什么？
- 如果中国只是一层皮，机制没有变化，那就不算真正的中国视角。

### Familiarity
- 孩子或普通中文读者需要补多少背景知识才能进入？
- 这个历史身份 / 职业今天是否仍有直觉？
- 有没有一个今天就能感受到的入口，再把历史放到后面解释？

### World Comparison
世界案例进入时必须有明确功能，而不是因为“模型顺手”。

## H01 的教训

v0.2 使用 1883 年北美铁路、电报送信少年和“两个正午”。

问题不在史实，而在表达：
- 观众先要理解电报和旧职业；
- 美国历史成为观看门槛；
- “标准时间 = 共享未来坐标”的核心反而被外壳遮住。

v0.4 改成：
> **“北京时间为什么在西安产生？”**

这不是简单把美国换成中国，而是找到一个只在中国语境里天然成立、同时直接暴露机制的事实入口。

## Rule of thumb

> **先找离作者和观众最近的真实惊讶，再去世界上找更远的证据。**
