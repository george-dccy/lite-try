# Creative Blueprint v0.1

Creative Blueprint 是世界机制故事引擎的核心中间语言。它位于“理解”与“表达”之间：上游不关心最终发在哪个平台；下游不得重新发明核心观点。

## Blueprint 必须回答
- **Question**：我真正想弄明白什么？
- **Mechanism**：现实中什么机制支撑这个问题？
- **Creative Hypothesis**：我做了什么创造性变换？
- **World / Premise**：作品里的规则是什么？
- **Human Stakes**：它怎样进入普通人的生活？
- **Task**：人物必须完成什么具体事情？
- **Reveal**：机制怎样通过动作一次次显现？
- **Knowledge Payload**：孩子能自然感受到什么？
- **Adult Layer**：成人可能多读到什么？
- **Open Question**：作品最后还留下什么值得想？
- **Renderer Hints**：什么表达形态可能合适？只做建议，不锁定。

## Gate
Blueprint 未经人工确认，不进入 Production。
