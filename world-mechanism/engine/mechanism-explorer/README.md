# Mechanism Explorer v0.1

Mechanism Explorer 是项目最核心的人机协作模块之一。它的目标不是回答问题，而是把“我觉得这里有点奇怪”推进成一个可以真正改变理解的机制模型。

## 输入
- 一个观察、新闻、生活困惑、知识点、历史现象或虚构念头
- 用户当前直觉
- 可选：已有资料

## 输出
1. Question Ladder
2. Mechanism Candidates
3. Mechanism Map
4. Counterfactuals
5. Evidence Gaps
6. Creator Notes：哪些地方最值得作者自己判断

## 禁止默认行为
- 不直接写成标题党选题。
- 不直接进入脚本。
- 不用“三个真相”“真正原因”替代分析。
- 不为了完整性把不确定因果补全。
- 不把模型最顺手的解释当唯一解释。

## 退出条件
- 已出现有解释力的 Mechanism Map；
- 用户明确表示“这层理解对我有启发”；
- 关键问题需要转研究阶段；
- 继续追问只增加术语，没有增加理解。
