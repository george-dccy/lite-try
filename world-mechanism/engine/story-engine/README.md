# Story Engine

Story Engine 不负责凭空“变得更戏剧化”，而负责把 Blueprint 中已经成立的机制变成事件。

## 输入
已确认 Creative Blueprint。

## 核心任务
- 选择最有行动力的人物关系；
- 给人物一个可执行的外部任务；
- 让世界规则不断参与任务；
- 用状态变化推进，而非用解释推进；
- 让重复动作逐次改义；
- 保持规则数量克制。

## 常见失败
- 人物只是知识讲解员；
- 故事靠不断追加设定；
- 冲突只来自误会，机制没有参与；
- 为了感动直接上死亡、离别、事故；
- 结尾解释“这个故事告诉我们”；
- 用金句替代人物选择。

## 输出
媒介无关的 Story Master，不包含具体镜头模型参数。
