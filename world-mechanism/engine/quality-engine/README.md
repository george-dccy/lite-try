# Quality Engine

质量不只检查“有没有错误”，还检查作品有没有被自动化掏空。

## A. Mechanism Review
- 是否真的解释了现象？
- 是否存在更简单的替代解释？
- 推演有没有跳步？

## B. Creative Review
- 创意脱离知识点后还值得看吗？
- 规则是否能持续产生后果？
- 是否出现模板化爆款腔？
- 是否过度依赖反转？

## C. Story Review
- 人物是否有行动？
- 外部任务是否明确？
- 每一段是否改变状态？
- 重复动作是否改义？

## D. Fact Review
- F/I/H/R 是否混淆？
- 数字、日期、引语是否有来源？
- 当代热点是否复核最新状态？

## E. Audience Review
- 孩子不懂深层含义时，故事是否仍完整？
- 成人层是否来自故事本身，而非作者强行解释？

## F. Authorship Review
最后必须问：
> 这件作品里，哪一部分只有“我”会这样选？

如果答案只剩模型执行质量，项目就偏离了目标。
