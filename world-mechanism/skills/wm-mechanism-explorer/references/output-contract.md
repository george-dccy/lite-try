# Output Contract

Default to compact, analytical prose. Do not bury the mechanism in a long essay.

## 1. Starting Point
Restate the creator's actual observation or seed without improving it into a headline.

## 2. Core Question
One question. It may be provisional.

## 3. Question Ladder
5–10 high-value questions, grouped only when useful.

## 4. Mechanism Candidates
2–4 candidates if uncertainty exists.

For each:
- explains;
- misses;
- distinguishing evidence.

## 5. Mechanism Map
A concise map with only relevant actors, forces, flows, feedback, time, and information.

## 6. Evidence Ledger
Use F / I / H / R.

## 7. Counterfactuals
Prefer 3 different operations. Trace consequences beyond first order.

## 8. Creator Gate
Leave real choices unresolved for the creator.

## 9. Optional Creative Hypotheses
Only if the task is "explore for creation."

Each hypothesis must name:
- real mechanism;
- transformation;
- expected behavioral consequences.

## 10. Status
Choose one:
- `candidate`
- `needs-research`
- `ready-for-editorial-gate`

Never mark `approved`. Approval belongs to the human / editorial gate.
