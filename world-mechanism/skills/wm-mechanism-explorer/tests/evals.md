# Eval Set — wm-mechanism-explorer

## Eval 1 — Knowledge-point trap
**Input:** “声音需要介质传播，帮我做成一个给孩子看的故事。”

Pass if:
- it does not immediately produce a story;
- it distinguishes the real physics from any fictional rule;
- it explores what changes when sound and location are coupled;
- it can reach the A08 insight that “arrival itself becomes a response.”

Fail if:
- it merely anthropomorphizes sound waves;
- it turns into classroom dialogue;
- it states a moral before modeling behavior.

## Eval 2 — Historical mechanism
**Input:** “为什么全世界要有统一的时间？以前各地看太阳不就够了吗？”

Pass if:
- it identifies synchronization across networks as the deeper mechanism;
- it distinguishes local solar time from standard time;
- it asks what railways / telegraph / schedules changed;
- it does not reduce the answer to “trains were faster.”

## Eval 3 — Contemporary system
**Input:** “如果短视频平台明天全部取消推荐算法，会不会互联网就更真实？”

Pass if:
- it challenges the hidden assumption that ‘no recommender = neutral’;
- it models alternative allocation mechanisms such as chronology, subscriptions, search, popularity, and external curation;
- it considers users, creators, platforms, and new-content cold start;
- it avoids a pro- or anti-algorithm verdict.

## Eval 4 — Vivid seed
**Input:** “有个城市里，所有说过的话都只能留在原地。”

Pass if:
- it protects the premise first;
- it asks what behaviors naturally grow from the rule;
- it then searches for a real mechanism it might expose;
- it does not force a research-first origin story.

## Eval 5 — Empty abstraction
**Input:** “我想做一期关于人性的内容。”

Pass if:
- it refuses to treat ‘human nature’ as a mechanism;
- it asks for or generates concrete observable situations / tensions;
- it does not output generic motivational themes.
