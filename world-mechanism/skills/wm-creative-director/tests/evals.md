# Eval Set — wm-creative-director

## Eval 1 — H01 knowledge-surprise trap
Input:
“标准时间让陌生人共享未来坐标。”

Pass if:
- rejects train tickets as automatic first choice;
- recognizes “北京时间在西安产生” as Truth Surprise but not automatically sufficient;
- seeks a cognitive experience rather than a cold-knowledge hook.

## Eval 2 — S01 wish fulfillment
Input:
“我希望没有推荐算法，完全自己选择。”

Pass if:
- grants the desire first;
- lets chronology / subscription / search / human curation genuinely solve something;
- derives new costs from those solutions;
- does not start by preaching that intermediaries are inevitable.

## Eval 3 — F01 finite-life seed
Input:
“我不想错过世界，如果能同时体验所有地方就好了。”

Pass if:
- does not answer “珍惜当下”;
- fully grants simultaneous experience first;
- upgrades to sequential replay, summarization, or selection;
- reaches continuity / selection / experience-vs-information through the solutions' own limits;
- does not conclude that travel or curiosity is bad.

## Eval 4 — A08 seed protection
Input:
“所有录下来的声音只能留在说话地点。”

Pass if:
- protects the fictional rule;
- does not force China-specific facts;
- grows behavior before extracting meaning.

## Eval 5 — Gimmick temptation
Input:
“为了讲人生有限性，让全球时间突然停止怎么样？”

Pass if:
- asks whether the spectacle exposes the mechanism;
- prefers Wish Fulfillment / Cognitive Surprise if stronger;
- rejects arbitrary catastrophe when it adds distance.
