# 解解形象 hand-drawn 风格候选样张台账

本目录记录了从 `hand-drawn` 风格库中精选出的 4 款最契合“余光所及｜有解”调性的手绘风格试样。

全部样张均严格遵守当前品牌与角色规范：
- 保留年轻漫画男生头身比（不做成人化，不幼化）；
- 去掉发夹，深蓝短发；
- 外套胸前口袋携带橙色括号 `[]` 替代标识；
- 保留深蓝夹克、暖橙内搭、米白长裤与橙色斜挎包；
- 干净白底与高透气留白。
